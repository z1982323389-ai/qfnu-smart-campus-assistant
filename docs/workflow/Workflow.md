# 曲智通 AI Workflow 文档

## 目标

曲智通的 AI Workflow 用于约束模型按校园事务咨询逻辑工作。它不是让模型自由聊天，而是将用户问题转化为可追溯、可核验、可继续查询的校园事务咨询建议。

## 总流程

```text
用户输入
  |
  v
输入清洗
  |
  v
意图识别
  |
  v
边界判断
  |
  |-- 超出范围 → 拒答与官方渠道提示
  |
  v
知识库检索
  |
  |-- 命中资料 → 基于来源生成结构化回答
  |-- 未命中资料 → 返回演示级结构化回答并提示资料不足
  |
  v
来源引用
  |
  v
相关推荐
```

## 意图分类

| 意图 | 说明 |
|---|---|
| `campus_service` | 校园办事咨询 |
| `freshman_guide` | 新生指南 |
| `scholarship` | 奖助学金 |
| `academic_affairs` | 教务政策 |
| `library` | 图书馆服务 |
| `notice` | 校园通知解读 |
| `department` | 部门联系方式 |
| `faq` | 高频问题 |
| `out_of_scope` | 超出范围或涉及个人数据 |

## 拒答规则

以下问题首版必须拒答：

- 查询成绩
- 查询课表
- 查询校园卡余额
- 查询宿舍电费
- 查询个人审批进度
- 要求处理身份证号、学号、手机号等敏感信息
- 要求系统替代学校部门办理业务

拒答不应简单说“不能”。更好的回答结构是：

1. 说明无法处理的原因。
2. 提醒项目不接入内部系统。
3. 建议用户前往官方系统或联系对应部门。
4. 提供可继续咨询的公开政策问题。

## 回答结构

校园办事类回答：

- 摘要
- 适用对象
- 建议核验步骤
- 材料提示
- 咨询渠道建议
- 注意事项
- 来源引用
- 相关推荐

通知解读类回答：

- 一句话摘要
- 影响对象
- 关键时间
- 需要行动
- 材料要求
- 风险提醒
- 来源

## 知识库命中策略

当前使用轻量关键词检索：

- 标题命中加权
- 标签命中加权
- 正文命中加权
- 分类过滤
- 结果按 score 排序

后续可以替换为：

- 向量检索
- 混合检索
- 文档切片
- 来源片段引用
- Coze 知识库能力

## Coze 集成策略

当前项目已预留 Coze 服务适配层。未配置 API Key 或 Coze 调用失败时，系统会返回演示级结构化答案，保证演示不中断。

正式接入时建议：

1. 在 Coze 中配置校园办事 Bot。
2. 将意图识别、知识库查询、回答生成、相关推荐、拒答机制拆分为 Workflow 节点。
3. 服务端 Route Handler 只负责参数校验、限流、调用 Coze 和统一响应。
4. 前端只展示结构化结果，不直接接触 API Key。

## 质量标准

- 无来源时不编造政策。
- 涉及个人数据时必须拒答。
- 回答必须包含下一步核验建议。
- 来源必须包含标题和更新时间。
- 高频问题应返回稳定结构。
