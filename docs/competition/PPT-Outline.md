# 曲智通答辩 PPT 大纲

## 第 1 页：封面

标题：曲智通 QFNU Smart Campus Assistant

副标题：曲阜师范大学 AI 校园事务咨询与信息核验助手

内容：

- 参赛主题：智创曲园 · 应用驱动新突破
- 项目简称：QSA
- 团队信息

## 第 2 页：问题背景

核心观点：校园信息很多，但学生需要先知道去哪里核验、如何准备。

内容：

- 通知分散在官网、学院页面、部门公告中
- 文件语言正式，学生需要转换成核验步骤
- 辅导员和老师重复答疑压力大
- 新生对校园服务入口不熟悉

## 第 3 页：产品定位

核心观点：曲智通不是聊天机器人，而是校园事务咨询前的信息核验入口。

内容：

- 基于公开资料
- 基于知识库
- 基于 AI Workflow
- 输出公开资料摘要、核验建议、咨询渠道和来源

## 第 4 页：目标用户

内容：

| 用户 | 场景 |
|---|---|
| 本科生 | 奖助学金、学生证、教务政策 |
| 研究生 | 培养政策、图书馆资源 |
| 新生 | 报到、校园服务 |
| 教师 | 通知解读、部门信息 |
| 辅导员 | 重复答疑、政策解释 |

## 第 5 页：首版功能

展示八个模块：

- 校园办事咨询
- 新生指南
- 奖助学金
- 教务政策
- 图书馆服务
- 校园通知解读
- 部门联系方式
- FAQ

## 第 6 页：核心演示

演示路径：

```text
首页 → AI 聊天 → 知识库检索 → 办事大厅 → 后台配置
```

重点问题：

- 学生证丢了需要先核验什么？
- 奖学金材料以哪里为准？
- 这条通知对我有什么影响？

## 第 7 页：AI Workflow

流程：

```text
输入清洗 → 意图识别 → 知识库检索 → 结构化回答 → 来源引用 → 相关推荐 → 拒答机制
```

说明：

- 降低幻觉
- 保持回答结构稳定
- 明确不能回答的问题

## 第 8 页：知识库设计

内容：

- 支持 Markdown、PDF、Word、TXT
- 分类、标签、来源、版本、更新时间
- 当前已实现轻量检索 API
- 后续可扩展向量检索

## 第 9 页：技术架构

技术栈：

- Next.js
- TypeScript
- TailwindCSS
- shadcn/ui
- Route Handler
- Coze API 适配层
- 文件化知识库
- Vercel 部署

## 第 10 页：安全边界

明确不做：

- 不查询成绩
- 不查询课表
- 不查询校园卡余额
- 不查询宿舍电费
- 不处理个人隐私数据

说明：

这个边界使项目更真实、更合规，也便于后续在授权范围内扩展。

## 第 11 页：创新点

内容：

- 从聊天转向事务咨询
- 从搜索转向核验建议
- 从泛回答转向来源引用
- 从一次性 Demo 转向可维护知识库
- 从功能堆砌转向轻量可演示

## 第 12 页：应用价值与 Roadmap

价值：

- 降低学生检索成本
- 减少重复答疑
- 提升公开信息服务体验
- 可扩展到学院和其他高校

Roadmap：

- 扩充公开资料
- 完善 Coze Workflow
- 增强后台编辑
- 获得授权后评估内部系统对接
