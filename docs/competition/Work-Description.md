# 曲智通作品说明书

## 作品概述

曲智通是面向曲阜师范大学师生的 AI 校园办事与信息服务平台。项目以公开资料、文件化知识库和 AI Workflow 为基础，帮助用户理解校园政策、整理办事流程、准备材料、解读通知并找到可能负责的部门。

项目定位不是聊天机器人，也不是校园百科，而是校园事务办理前的信息核验与咨询引导入口。首版不接入学校内部系统，不查询成绩、课表、校园卡余额、宿舍电费或个人审批进度，回答仅基于公开资料、示例知识库和预设 Workflow 生成。

## 建设背景

高校师生日常办事经常面对三个问题。第一，政策和通知分散在不同官网、学院页面和公告中。第二，正式文件语言较为规范，学生需要花时间转化为“我该做什么”。第三，辅导员和老师经常重复回答相似问题，答复口径需要统一。

曲智通通过 AI 把公开资料转化为结构化咨询建议，包括适用对象核验、建议步骤、材料提示、咨询渠道、注意事项和来源引用。这个方案不依赖内部权限，适合在比赛周期内做出可运行、可演示、可继续扩展的版本。

## 目标用户

| 用户 | 典型需求 | 项目价值 |
|---|---|---|
| 本科生 | 奖助学金、学生证、教务政策、图书馆服务 | 快速了解流程和材料 |
| 研究生 | 培养政策、奖学金、图书馆资源 | 降低文件检索和理解成本 |
| 新生 | 报到、校园生活、常用部门 | 快速熟悉学校服务 |
| 教师 | 通知解读、部门联系方式 | 快速获取公开资料摘要 |
| 辅导员 | 重复答疑、政策解释 | 统一答复口径 |

## 核心功能

首版覆盖八个模块：

- 校园办事咨询
- 新生指南
- 奖助学金
- 教务政策
- 图书馆服务
- 校园通知解读
- 部门联系方式
- FAQ

其中 AI 聊天和知识库检索是核心链路。用户输入校园事务问题后，系统识别意图、检索知识库、生成结构化咨询建议并展示来源。涉及内部系统和个人隐私的问题会触发拒答机制。

## 系统架构

系统采用 Next.js、TypeScript、TailwindCSS、shadcn/ui 和 Route Handler。AI 调用在服务端完成，前端不暴露 API Key。知识库采用文件化目录和结构化元数据，当前已实现轻量关键词检索，后续可扩展为向量检索。

```text
用户页面
  |
  v
Next.js App Router
  |
  v
Route Handler API
  |
  v
AI Service + Campus Workflow
  |
  v
Knowledge Search
  |
  v
File-based Knowledge Base
```

## AI Workflow

AI Workflow 包括：

- 输入清洗
- 意图识别
- 知识库检索
- 结构化回答
- 来源引用
- 相关推荐
- 拒答与人工引导

当前已实现演示级校园 Workflow。系统会识别奖助学金、新生指南、教务政策、图书馆服务、校园通知、部门联系方式等意图，并对成绩、课表、校园卡余额、宿舍电费等内部系统问题拒答。

## 知识库设计

知识库支持 Markdown、PDF、Word 和 TXT。当前阶段以示例 Markdown 和结构化元数据验证链路。每条知识条目包含标题、分类、标签、适用对象、校区范围、来源类型、来源名称、来源链接、版本、更新时间和状态。

知识库分类包括：

- `campus-services`
- `freshman-guide`
- `scholarships`
- `academic-affairs`
- `library`
- `notices`
- `departments`
- `faq`

## 安全与边界

项目遵守以下边界：

- 不接入学校内部数据库
- 不查询个人成绩、课表、校园卡余额、宿舍电费
- 不处理身份证号、学号、手机号等敏感信息
- API Key 仅保存在服务端环境变量
- AI 接口具备限流和错误处理
- 无可信来源时不编造政策
