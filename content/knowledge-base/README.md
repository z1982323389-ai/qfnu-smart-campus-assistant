# 曲智通知识库

本目录用于存放曲智通首版文件化知识库资料。知识库支持 Markdown、PDF、Word、TXT，当前阶段先以示例 Markdown 和结构化元数据验证检索链路。

## 分类

- `campus-services`：校园办事咨询
- `freshman-guide`：新生指南
- `scholarships`：奖助学金
- `academic-affairs`：教务政策
- `library`：图书馆服务
- `notices`：校园通知解读
- `departments`：部门联系方式
- `faq`：高频问题

## 元数据要求

每条资料后续都应包含：

- 标题
- 分类
- 标签
- 适用对象
- 校区范围
- 来源类型
- 来源名称
- 来源链接
- 版本
- 更新时间
- 状态

## 边界

知识库只收录公开资料，不收录成绩、课表、校园卡余额、宿舍电费、个人审批进度等内部系统或个人隐私数据。
